Nesse repositório é possível encontrar quatro projetos referentes a *Educação*, repasse de verba e organização e reagrupamento de dados. O primeiro projeto ****SIMULADOR DE REPASSE DO PNAE**** simula o cálculo do repasse financeiro do PNAE (Programa Nacional de Alimentação Escolar) para uma escola, com base no número de matrículas por modalidade de ensino no Excel, e está incorporada uma automação em VBA que registra cada simulação em um banco de dados dentro da própria planilha. O segundo projeto ****PAINEL CENSO**** organiza e cruza dados do Censo Escolar de 2024 em um Dashboard no Excel. O terceiro projeto também é um simulador do repasse do PNAE, porém no Python. O quarto projeto é também um painel com uma reorganização das informações do CENSO, só que no Python.
