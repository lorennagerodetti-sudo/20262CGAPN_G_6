Nesse repositório é possível encontrar quatro projetos referentes a *Educação*, repasse de verba e organização e reagrupamento de dados. O primeiro projeto ****SIMULADOR DE REPASSE DO PNAE**** ele simula o cálculo do repasse financeiro do PNAE (Programa Nacional de Alimentação Escolar) para uma escola, com base no número de matrículas por modalidade de ensino no excel, e está incorporada uma automação em VBA que registra cada simulação em um banco de dados dentro da própria planilha. O segundo projeto ****PAINEL CENSO**** ele organiza e cruza dados do Censo Escolar de 2024 em um dashboarde no excel. O terceiro projeto também é um simulador do repasse do PNAE, porém no Python e o quarto e último projeto é também um painel com uma reorganização das informações do CENSO, só que no Python.
