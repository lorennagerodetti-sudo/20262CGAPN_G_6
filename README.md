Esse portifólio apresenta quatro projetos focados na obtenção de dados referentes a educação por meio das plateformas Excel e Python.
O projeto 1 *Simulador de Repasse do PNAE* realiza o calculo do repasse financeiro do PNAE por meio do Excel, tendo uma atualizada pela automação com VBA com o finalidade de criar um banco de dados sobre os usuários, enquanto o Projeto 3 apresenta a mesma funcionalidade através do Python. O projeto 2 *Painel Censo* apresenta um dashboard que facilita a vizualização e busca dos dados do Censo Escola de 2024 por meio do Excel, o projeto 4 realiza o mesmo propósito por meio do Python.
